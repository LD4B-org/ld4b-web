PINTIA4B-25G-L 1260–1380 nm fiber-coupled PIN photodiode with TIA, 25 Gbps

PIN photodiode with a low-noise transimpedance amplifier with auto gain control coupled to an optical fiber and packaged into a hermetic case.

Request a quote Datasheet PDF (330 KB)

Main features

  • Maximum optical input power 2 dBm
  • Operation wavelength 1260 – 1380 nm
  • Data rate: 25 Gbps
  • Sensitivity: -14 dBm
  • Package types: coaxial with or without bracket
  • Low back reflection, return loss RL = 35 dB
