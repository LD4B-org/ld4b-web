PD4B-250-P5-LC 500–2150 nm fiber-coupled PIN photodiode

InGaAs PIN photodiode with extended spectral range coupled to an optical fiber and packaged into a hermetic case.

Main features

  • Maximum optical power: 5 mW
  • Typical responsivity: 1.3 A/W at 1950 nm
  • Cut-off wavelength: 2150 nm
  • Package types: coaxial with or without bracket, BTF-14-pins
  • Coupling technologies: R50/R30 (low back reflection)

Ordering information

Coupling technology

  • R50: back reflection -50 dB (SM06, SM1, SM3 and SM1950 fiber, FA, SA or N connector)
  • R30: back reflection -30 dB (MM5, MM6, MM105 fiber)

Case type

  • COAX: compact coaxial (low duty cycle pulse mode only)
  • COAXB: compact coaxial with a bracket
  • BTF: BTF-14-pins

Pinout code

  • 7: pin assignment in the datasheet (PDF)

Fiber type

  • SM06: SM, Corning Hi-1060, furcation tubing ⌀0.9 mm
  • SM1: SM, G.657.A1, Corning SMF-28 Ultra, furcation tubing ⌀0.9 mm or BSM1 ⌀0.25mm
  • SM3: SM, G.657.B3, Corning ClearCurve ZBL, furcation tubing ⌀0.9 mm or BSM3 ⌀0.25mm
  • SM1950: SM, Coherent SM1950
  • MM5: MM, 50/125, OM3, furcation tubing ⌀0.9 mm
  • MM6: MM, 62.5/125, OM1, furcation tubing ⌀0.9 mm
  • MM105: MM, 105/125, NA=0.22, Coherent S105/125-22A, furcation tubing ⌀0.9 mm

Connector type

  • FU: FC/UPC (MM5, MM6, MM105)
  • FA: FC/APC (MM5, MM6, MM105)
  • N: no connector (scissors cut)

Other type: on request

Fiber length

  • 0.5: 500+/-50 mm
  • 1.0: 1000+/-100 mm

Other length on request

Every module is built to order: package, fiber type and length, and connector are chosen per order.
