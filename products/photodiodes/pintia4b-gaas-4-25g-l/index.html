PINTIA4B-GaAs-4.25G-L

GaAs PIN photodiode with a low-noise transimpedance amplifier with auto gain control coupled to an optical fiber and packaged into a hermetic case.

Request a quote Datasheet PDF (331 KB)

Main features

  • Maximum optical input power 1 mW
  • Operation wavelength 770 – 860 nm
  • Data rate: 4.25 Gbps
  • Sensitivity: -21 dBm
  • Package types: coaxial with or without bracket
  • Low back reflection, return loss RL = 40 dB
