LD4B-1350-DFB-10G-20

Laser diode coupled to an optical fiber and packaged into a hermetic case.

Main features

  • Wavelength: 1350 nm
  • Cavity type: DFB
  • Optical power in CW mode in single-mode fiber: 20 mW
  • Instantaneous linewidth ~1 MHz
  • Data rate 10 Gbps
  • Package types: coaxial, coaxial with bracket, 14 pins BTF
  • Built-in monitor photodiode

Case type

  • COAX: compact coaxial (low duty cycle pulse mode only)
  • COAXB: compact coaxial with a bracket
  • COAXH: compact coaxial with an H-shaped bracket for mounting to a board
  • TH: compact coaxial with a bracket compatible to Thorlabs mount
  • BTF: 14-pins BTF type 1 (Pump) for active thermal stabilization (TEC and thermistor)

Pinout code

  • 12: pin assignment in the datasheet (PDF)

Fiber type

  • SM1: SM, G.657.A1, Corning SMF-28 Ultra, furcation tubing ⌀0.9 mm or BSM1 ⌀0.25mm
  • SM3: SM, G.657.B3, Corning ClearCurve ZBL, furcation tubing ⌀0.9 mm or BSM3 ⌀0.25mm
  • MM5: MM, 50/125, OM3, furcation tubing ⌀0.9 mm

Other type on request

Connector type

  • FU: FC/UPC (SM1, SM3)
  • FA: FC/APC (SM1, SM3, SMP13)
  • SU: SC/UPC (SM1)
  • SA: SC/APC (SM1)
  • N: no connector (scissors cut)

Other type: on request

Test measurements

  • CW: CW mode (electro-optical parameters at T=25+/-5 C and spectrum)
  • P: Pulse mode (pulse duration 5 us, duty cycle 0.5%, at T=25+/-5 C)
  • CWP: both CW and pulse mode
