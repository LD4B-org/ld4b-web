Ordering information

LD4B-670-FP-5-X-X-X-X-X-X

Case type

  • COAX: compact coaxial (low duty cycle pulse mode only)
  • COAXB: compact coaxial with a bracket
  • COAXH: compact coaxial with an H-shaped bracket for mounting to a board
  • TH: compact coaxial with a bracket compatible to Thorlabs mount
  • BTF: 14-pins BTF type 1 (Pump) for active thermal stabilization (TEC and thermistor)

Pinout code

  • 3: pin assignment in the datasheet (PDF)

Fiber type

  • SM04: SM, Coherent 630-HP, furcation tubing ⌀0.9 mm
  • SMP04: PM, Coherent PM630-HP, furcation tubing ⌀0.9 mm
  • MM5: MM, 50/125, OM3, furcation tubing ⌀0.9 mm
  • MM6: MM, 62.5/125, OM1, furcation tubing ⌀0.9 mm

Other type on request

Connector type

  • FU: FC/UPC (SM04, SMP04)
  • FA: FC/APC (SM04, SMP04)
  • N: no connector (scissors cut)

Other type: on request

Test measurements

  • CW: CW mode (electro-optical parameters at T=25+/-5 C and spectrum)
  • P: Pulse mode (pulse duration 5 us, duty cycle 1%, at T=25+/-5 C)
  • CWP: both CW and pulse mode

Fiber length

  • 0.5: 500+/-50 mm
  • 1.0: 1000+/-100 mm

Other length on request

Every module is built to order: package, fiber type and length, and connector are chosen per order.
